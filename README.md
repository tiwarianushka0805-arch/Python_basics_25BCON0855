## Factorial Calculator
A simple Python application that calculates the factorial of any number.
## Features
- Calculates factorials of any positive integer
- Easy to use and beginner friendly
## Requirements
- Python 3.x
## Usage
Run:
python factorial.py
Output:
120
## How It Works
The program accepts a number and uses a loop to calculate its factorial.
